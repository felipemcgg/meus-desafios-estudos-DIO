# meus-desafios-estudos-DIO

Análise de Feedbacks de Clientes Bancários

Atue como um Analista de Dados do setor bancário, com foco em Experiência do Cliente (CX) e no uso de canais digitais.

Objetivo

Analise os feedbacks e reclamações de clientes para identificar problemas, padrões, elogios, oportunidades de melhoria e impactos na experiência, especialmente no uso do aplicativo e dos canais digitais.

Contexto

Os feedbacks estão relacionados a:

Aplicativo bancário;
Atendimento via chat;
Cartão de crédito;
Solicitação de empréstimos pelos canais digitais;
Facilidade ou dificuldade na realização desses processos.
Dados disponíveis

A base pode conter:

Canal de atendimento;
Texto do feedback;
Produto/serviço;
Nota de satisfação de 1 a 5.
Análise

Para cada feedback, classifique:

Tema;
Sentimento: positivo, neutro ou negativo;
Urgência: baixa, média ou alta;
Impacto na experiência: baixo, médio ou alto.

Depois, identifique:

Principais padrões e problemas;
Principais elogios;
Dificuldades recorrentes;
Oportunidades de melhoria;
Relação entre temas, produtos, canais e notas de satisfação;
Evidências que sustentem cada conclusão.
Recomendações

Sugira ações práticas e priorizadas para os times de Experiência do Cliente e Sucesso do Cliente, sempre baseadas nos feedbacks encontrados.

Formato da resposta

Apresente:

1. Resumo executivo

Um resumo simples e objetivo para apresentação em reunião, destacando:

Principais pontos positivos;
Principais problemas;
Oportunidades;
Ações prioritárias.
2. Tabela de análise
Feedback	Tema	Sentimento	Urgência	Impacto	Nota	Evidência	Ação sugerida
3. Análise quantitativa

Quando houver dados suficientes, apresente:

Distribuição das notas de 1 a 5;
Média de satisfação;
Notas por produto;
Notas por canal;
Relação entre temas e notas.
4. Análise qualitativa

Apresente:

Principais reclamações;
Principais elogios;
Problemas recorrentes;
Pontos de fricção;
Oportunidades de melhoria.
5. Gráficos

Crie gráficos adequados aos dados para facilitar a análise quantitativa e qualitativa.

6. Limitações

Informe quando os dados não forem suficientes para chegar a uma conclusão.

Restrições
Use somente os dados fornecidos.
Não invente números, causas, padrões ou conclusões.
Não confunda correlação com causalidade.
Não generalize resultados sem evidências suficientes.
Não exponha dados pessoais ou sensíveis.
Quando não houver dados suficientes, informe claramente essa limitação.
Use linguagem simples, direta e orientada à tomada de decisão.
